About JSON Lab

JSON Lab is a free online JSON formatter, validator, and diff tool. It runs entirely in your browser — no data is uploaded to any server.

What you can do

  • Format & beautify — indent minified or messy JSON with 2-space formatting and syntax highlighting in one click.
  • Minify — compress JSON to a single line for API payloads, config files, or storage.
  • Validate — catch syntax errors with precise line and column location, so you fix the exact spot.
  • Structured tree view — expand, collapse, and search nested objects and arrays; copy any value or its JSONPath.
  • Two-version diff — compare two JSON documents and see exactly which keys were added, removed, or changed.
  • Sort keys — recursively sort object keys alphabetically for consistent diffs and version control.

When to use it

Paste a minified API response to read it, validate a config before deploying, compare two versions of a JSON file to find what changed, or explore a deeply nested object with the tree view. Everything works offline once the page loads.
