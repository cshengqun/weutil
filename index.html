What you can do with WeUtil

Every tool is designed to be fast, privacy-friendly, and immediately useful. No accounts, no ads in your way, no data sent to a server — your input never leaves your browser.

JSON Lab — format, validate and diff JSON

When you paste minified or malformed JSON from an API response, log file, or config, JSON Lab makes it readable in one click. It is built for the everyday tasks developers run into dozens of times a day.

  • Format & beautify — indent messy JSON with 2-space formatting and syntax highlighting.
  • Minify — compress to a single line for payloads, configs, or storage.
  • Validate — catch syntax errors with line and column location, so you fix the right spot.
  • Structured tree view — expand, collapse, and search nested objects and arrays; copy any value or JSONPath.
  • Two-version diff — see exactly which keys were added, removed, or changed between two JSON documents.

Epoch Lab — unix timestamp converter with time zones

Timestamps show up everywhere: logs, databases, APIs, cookies. Epoch Lab converts between epoch time and readable dates in both directions, and because servers and teams span the globe, it lets you view the same instant in any time zone.

  • Timestamp to date — auto-detects seconds, milliseconds, microseconds and nanoseconds from the digit length.
  • Date to timestamp — parse YYYY-MM-DD HH:mm:ss, ISO 8601 with offsets, or plain dates; output in s, ms, µs and ns.
  • Any time zone — switch the output between UTC, your local zone, or any IANA zone such as Asia/Tokyo, America/New_York, or Europe/London. Daylight saving time is handled automatically.
  • Multiple formats — ISO 8601, RFC 2822, locale string, and relative time ("3 hours ago").
  • Live clock — copy the current epoch in seconds or milliseconds with one click.
